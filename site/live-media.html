What joining means

RelaySwarm uses public Nostr relays to find viewers, then WebRTC to exchange verified media. Connected peers can see one another's network addresses. Sharing continues while you listen, using up to 4 MiB/s of upload and a 64 MiB media cache. The room shares temporary listener handles and media-transfer readings so you can see its activity. An audience that can give something back

Your audience can carry the stream.

Every viewer normally asks the server for another piece of video. RelaySwarm lets a browser supply a piece it already has to another listener. The counters above show whether that is happening in this session.

  1. The origin starts it.Your encoder publishes to Sapflow. Sapflow packages the media as HLS for your player. This public mix is a recording served as HLS from the media host.SRT / RTMP → HLS
  2. The audience can help.Viewers find each other through Nostr relays and exchange video directly with WebRTC. Every received segment is checked before it reaches the player.RelaySwarm / verified bytes
  3. The music keeps going.No useful peer, or a missed deadline? The player returns to the origin. With an independently operated relay and credential issuer configured, Spry TURN can connect browsers that need a relayed route.Origin fallback / optional TURN

Build with it

Your stream.
Your stack.

Keep the encoder and player you already know. Put a small Rust origin behind them, add peer delivery where it helps, and run the pieces on infrastructure you control.

01

Sapflow

RUST / ORIGIN + MEDIA LIBRARIES

From your encoder to the browser. Receive SRT or RTMP, package Low-Latency HLS and keep an MP4 recording. Run the native server or embed the media core.

Run Sapflow ↗Integration docs
02

RelaySwarm

WEBRTC / EXPERIMENTAL BROWSER LIBRARY

Put viewers in the delivery path. Exchange verified HLS segments over direct browser connections, with a bounded peer attempt before normal HTTP fallback.

Use RelaySwarm ↗Integration docs
03

Spry TURN

NATIVE RUST / UDP + TCP + TLS

Connect peers across awkward networks. Run a small standalone TURN server or embed the Rust library. Shared-secret credentials and bounded resources are built in.

Get Spry 0.2.1 ↗Server guide

MIT-licensed projects with their own dependency notices. The public listening room uses direct peers and origin fallback. Automatic TURN access requires an independently operated relay and credential issuer; none is configured here. The local comparison can exercise Spry and coturn with the same media.

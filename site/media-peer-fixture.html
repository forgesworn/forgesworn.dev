The tools

Build the stack
your stream needs.

Start with a small origin. Add peer delivery or a TURN relay when your application needs them. Each project has its own job, source and setup guide.

Early releases · Rust

Sapflow

Get from encoder to browser.

Receive SRT or RTMP, package Low-Latency HLS, and keep an MP4 recording. Run the Rust origin on your server or use its media libraries in your application.

  • SRT
  • RTMP
  • LL-HLS
  • fMP4

Rust crates are available now. Swift and Kotlin SDK work brings the shared media core to native publishers.

Run Sapflow ↗Read the docs
Experimental · Browser

RelaySwarm

Let viewers help deliver the stream.

Exchange verified HLS media between viewers using WebRTC. Keep the origin available when peers can't supply a part, with Nostr relays helping viewers find each other.

  • Verified media
  • WebRTC
  • Nostr

Explore the browser library and its integration examples. Your application chooses its discovery relays and ICE servers.

Try RelaySwarm ↗Integration docs
0.2.1 · Early release

Spry TURN

Give peers another way to connect.

Run a small native TURN server with UDP, TCP and TLS client transports, shared-secret credentials and bounded resources. Use it standalone or embed the Rust library.

  • UDP
  • TCP
  • TLS
  • Native Rust

Websites use an external relay. The separate WASM build supplies a packet codec. Native downloads cover macOS and Linux ARM64.

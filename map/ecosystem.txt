# ForgeSworn ecosystem map.
#
# This file is the whole map. Edit it and run `npm run map`; the renderer lays
# it out and writes a dark screen version (map/ecosystem-map.png) and a light,
# one-page print version (map/ecosystem-map-a4.pdf).
#
#   key: value                    header settings, before the first section
#   ## Section title | colour     starts a section (gold, blue, green, red,
#                                 purple, teal, rose, amber or a #hex)
#   repo-name                     an entry, labelled with the repo name
#   repo-name = Display Label     an entry with its own label
#   repo-name = Label | early     early or prototype work: dashed ring
#   repo-name = Label | spec      a specification, not a runtime: dotted ring
#   + Name = detail               a standard, shown as a badge under the tiles
#   + caption                     the caption over a section's badges
#
# Blank lines and lines starting with # are ignored. An entry's icon is
# map/icons/<repo-name>.png or .svg when one exists, a monogram otherwise.
# Names are checked against forgesworn-repos.json, so a typo or a repo that
# left the catalogue is reported rather than drawn, and catalogued repos that
# are missing from the map are listed.
#
# The map shows one entry per product a person could pick up on its own or
# with someone else's software. A language port or a piece that only works
# with one other ForgeSworn product stays off the map; see map/README.md.
#
# Status markers come from reading the code, not from version numbers: see
# map/README.md for how they were judged.
